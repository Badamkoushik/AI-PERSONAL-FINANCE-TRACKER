# AI-Powered Personal Finance Tracker (FinTrack)

## Live Demo
[Click here to visit FinTrack](https://fintrack-frontend-kmni.onrender.com)

## Project Description
FinTrack is an AI-powered personal finance management application
that helps users track income, expenses, budgets and financial activities.

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication
- Redux Toolkit
- Tailwind CSS
- Recharts
- OpenAI API

## Key Features
- User Registration and Login
- Income and Expense Tracking
- Budget Management
- AI-Powered Financial Insights
- Financial Data Visualization
- PDF Report Generation
